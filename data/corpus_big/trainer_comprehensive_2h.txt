=== COMMAND LINE & POWERSHELL MASTERY ===
Command Line Fundamentals:
- Windows cmd: dir, cd, mkdir, copy, move, del, ren, type, echo, set, path
- PowerShell: Get-ChildItem, Set-Location, New-Item, Copy-Item, Move-Item, Remove-Item, Rename-Item, Get-Content, Set-Content, $env:PATH
- Batch scripting: @echo off, %variables%, if/else, for loops, call, exit
- PowerShell scripting: functions, parameters, pipelines, objects, modules

Advanced Command Operations:
- Process management: tasklist, taskkill, Get-Process, Stop-Process
- Network: ipconfig, ping, netstat, tracert, Get-NetAdapter, Test-Connection
- System: systeminfo, powercfg, chkdsk, sfc, Get-ComputerInfo, Get-Service
- File operations: robocopy, xcopy, attrib, compact, Get-FileHash, Compress-Archive

PowerShell Advanced Features:
- Objects and pipelines: Get-Process | Where-Object {$_.CPU -gt 10} | Select-Object Name, CPU
- Remoting: Enter-PSSession, Invoke-Command, New-PSSession
- Modules: Import-Module, Get-Module, Find-Module, Install-Module
- Desired State Configuration: configuration scripts, nodes, resources
